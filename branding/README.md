# Branding

| Folder | Mark |
| --- | --- |
| `logo/` | G Monogram, the primary logo used across web and mobile |
| `logo-variant/` | Board G, an alternate mark |
| `store/` | Play Store and App Store screenshots, feature graphic and listing copy |

Each folder holds:

- `svg/mark.svg`: the mark on light backgrounds; `mark-dark.svg` for dark backgrounds; `mark-black.svg` and `mark-white.svg` for one-colour use.
- `svg/lockup.svg` and `svg/lockup-dark.svg`: the mark with the wordmark. The wordmark is Plus Jakarta Sans ExtraBold converted to outlines.
- `png/`: the mark at 16 to 1024 px, both lockups, and 1024 px app icons on white and on ink.
- `favicon.ico`: 16, 32 and 48 px.

## Colours

| Token | Light | Dark |
| --- | --- | --- |
| Grey | `#727376` | `#b4b5b9` |
| Wine | `#833b4b` | `#c27b8e` |
| Ink (wordmark "Grey") | `#1e1f22` | `#ffffff` |

The marks are drawn on a 64-unit grid. Keep clear space of at least the wine dot's diameter around the mark.
